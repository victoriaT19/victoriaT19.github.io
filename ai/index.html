tokenprof: token profiler for LLM agents

2026 · paper for the Gemma 4 Developer Agent competition

A proxy between an agent and any OpenAI-compatible API that logs every call (tokens, cache, cost, latency) and points at the waste: context resent on every call, broken prompt caches, loops.

  • Gemma 4 coding agents (E2B and E4B) on the 129 public tasks of the competition: 8 full runs, 1,032 attempts, one identical re-run as a noise control
  • About 40% of prompt tokens were a fixed prefix resent on every call; profiler-guided changes cut E2B's context overflows from 29% to 0% (Fisher's exact test, p < 0.01)
  • Written up as a paper, with every trace published

Pit wall: F1 race strategy with an LLM race engineer

2026 · updated after every session of the remaining races

A strategy engineer built from public timing data and Pirelli's tyre nominations, with a chat where an LLM answers by running the same calculations as the dashboard.

  • Agent: Gemma 4 31B with 10 tools (strategy plan, whole-field simulation, results, standings), on a chain of free models that switches when one is rate-limited and shows each tool call live; 16/16 in an automatic eval, and the fallback model answered all it reached
  • Models: tyre degradation, Monte Carlo pit strategy and a lap-by-lap simulation of the whole field with retirements; finishing order from a Plackett-Luce ranking model ensembled with gradient boosting (Spearman 0.705 vs. 0.677 for the grid over 68 races)
  • Honest backtests: leakage-free, reported when negative; pit timing is no better than a historical baseline, and a leak hidden in a tie-break was found and fixed

Resonance: Gemma 4 physics tutor

2026 · Gemma 4 Good Hackathon

Gemma 4 E2B fine-tuned to answer in two levels: the intuition first, then the derivation.

  • 330 question–answer pairs distilled from Gemma 4 31B, filtered, then QLoRA on one T4
  • Base vs. tuned on 20 held-out questions with an LLM judge and a sign test: aggressive training made the physics worse (2.3 vs. 3.3); the conservative version kept it and always got the format right

Kaggle · medical imaging

LLM as a labeler for knee MRI reports

2026 · RSNA Knee Abnormality Detection

An LLM read 4,407 radiology reports and graded 12 findings; a monotonic calibration on the 58 expert-labelled studies turned the grades into soft labels for an image model.

  • Labels vs. experts: mean AUC 0.81
  • Image model trained on them: AUC 0.828 on the private leaderboard (late submission)
